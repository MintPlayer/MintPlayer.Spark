Commit graph

Every repository page shows its history as a commit graph, every branch and tag in one view, with the coverage of each commit on its node. You see at a glance where coverage went up, where it fell, and which commit did it.

There is nothing to switch on: the graph appears the first time you open a repository.

  • One branch: the branch selector narrows the graph to a branch and its ancestry.

} @case ('current') {
  • A push refreshes the graph within moments, for a repository that has the GitHub App installed.
  • Opening the page refreshes a graph that has not been refreshed for a while; you see the rows it has meanwhile.
  • Every hour the graphs are refreshed as a safety net, which is also how a public repository without the App, which sends no pushes, stays current.
  • A graph nobody opened for 60 days is cleared to save space; the next visit copies it again and shows syncing first.
